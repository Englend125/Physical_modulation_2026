# Billiard_simulation
M2. Бильярд на гладком столе. Смоделируйте столкновение идеально
гладкого бильярдного шара с другим шаром. Детально смоделируйте
упругое столкновение, решая дифференциальное уравнение на основе 2-го
закона Ньютона, если шар считать деформируемым согласно закону Гука
𝐹𝐹 ∼ −Δ𝑥𝑥 (или закону Герца 𝐹𝐹 ∼ −Δ𝑥𝑥3/2 ). Рассмотрите разные варианты
столкновений (лобовое, под углом, шары одинаковой или разной массы,
покоящиеся и движущиеся и т.п.). Сравните результаты расчётами на основе
применения законов сохранения энергии и импульса.
